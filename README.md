
# Elementa – Purple Edition 🧪

An interactive Periodic Table of Elements built using HTML, CSS, and JavaScript.

## ✨ Features
- All 118 chemical elements
- Modern purple-themed design
- Search elements by name, symbol, or atomic number
- Filter elements by category
- Animated pop-up with element details
- Responsive layout

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript

## 🚀 How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.

## 📸 Project
Explore all 118 elements through a simple and interactive interface.
